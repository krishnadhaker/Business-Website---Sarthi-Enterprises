# Sarthi Enterprises – Business Website

A responsive, multi-page business website developed for **Sarthi Enterprises**, a business specializing in trading, transportation, Alternative Fuel Resources (AFR), and civil construction services.

The website provides an online presence for the company, showcasing its services, products, business information, and contact details through a user-friendly interface.

# Website Features

- Home Page: Introduction to the company and its business activities.
- About Us: Company background and business information.
- Products: Overview of available products and materials.
- AFR Services: Information about Alternative Fuel Resources.
- Transportation: Transportation-related services.
- Civil Construction: Details about construction services.
- Gallery: Visual presentation of business activities.
- **Contact Page:Contact information and customer enquiry section.
- **Responsive Design: Layout designed to support different screen sizes.
- Basic SEO: Includes `robots.txt` and `sitemap.xml` for search engine crawling and indexing.

# Technologies Used

- HTML5 – Website structure and content.
- CSS3 – Styling, layouts, and responsive design.
- JavaScript – Interactive elements and website functionality.

# How to Run Locally

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html`.

4. Run the website using the **Live Server** extension.

5. The website will open in your default browser.
